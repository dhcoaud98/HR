단어 공부로 산으로 가지 않도록, 모든 용어에 **꼭 알기 / 대충 알기 / 몰라도 됨** 판정을 붙였습니다.

## 읽는 법

| 판정 | 의미 |
|---|---|
| 🔴 꼭 알기 | HR 실무·면접에서 바로 쓰입니다. 뜻과 '왜 중요한지'까지 읽어 두세요. |
| 🟡 대충 알기 | 한 줄 뜻만 알면 기사를 읽는 데 지장 없습니다. |
| ⚪ 몰라도 됨 | 넘어가도 됩니다. 걸리면 그때 한 줄만 보세요. |

- ⚪ 용어가 **30일 넘게 다시 안 나오면 아래로 자동으로 접힙니다.** 다시 나오면 목록에 돌아옵니다.
- 다 익힌 용어는 매주 금요일 올라오는 **[용어집 주간 체크](https://github.com/dhcoaud98/HR/issues?q=label%3A%EC%9A%A9%EC%96%B4%EC%A7%91)** Issue에서 체크하면, 다음 날 아침 '이제 아는 용어'로 옮겨집니다.
